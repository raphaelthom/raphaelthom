## 🌊 Featured project: Surf & Windsurf Forecast

A live web app that turns raw weather and ocean data into one answer: *should I go out today, and when?*
It pulls hourly forecasts from the Open-Meteo APIs, rates every hour with explainable rules (adjusted to the spot and your skill level),
and shows the result in a dashboard.

**[Open the live app](https://surf-app-rt.streamlit.app/)** · **[Read the code and how it was built](https://github.com/raphaelthom/surf-app)**

`Python` `pandas` `Plotly` `Streamlit` `pytest` `GitHub Actions` `REST APIs`
